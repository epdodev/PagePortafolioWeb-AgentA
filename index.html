Luuv • Aplicación Web de Citas

En Producción Full Stack

Plataforma interactiva de citas diseñada para conectar personas de forma dinámica y segura según afinidades reales. Integra un algoritmo de emparejamiento por intereses compartidos, interacción ágil de likes y dislikes, mensajería instantánea en tiempo real y funciones exclusivas para usuarios Premium.

Características Principales:

  • Emparejamiento inteligente: Match por intereses mutuos.
  • Chat en tiempo real: Mensajería fluida e instantánea.
  • Interacción dinámica: Sistema ágil de Likes y Dislikes.
  • Suscripción Premium: Filtros y beneficios exclusivos.
  • Gestión de cuentas: Autenticación y login protegido.
  • Cloud Hosting: Despliegue en la nube con Render.

Tecnologías Empleadas:

  • Java
  • Spring Boot
  • WebSockets (Real-Time)
  • SQL / Base de Datos
  • HTML5 / CSS3
  • JavaScript
  • Render Cloud
