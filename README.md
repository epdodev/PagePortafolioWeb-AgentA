# Perfil Profesional & Portafolio Digital - Victor Moran

Portafolio profesional y perfil curricular digital accesible de **Victor Moran**, estudiante de **Ingeniería en Software** de la Universidad de Guayaquil con experiencia en desarrollo de sistemas, atención al cliente y gestión operativa de puntos de venta e inventario.

---

## 🌟 Características Destacadas

* **Pantalla de Entrada con Efecto Frosted Glass (Gateway Intro):**
  * Presentación ejecutiva inicial con foto de perfil, estado profesional activo, bio resumida y botones de llamada a la acción.
  * Fondo ambiental difuminado (*blur* dinámico) del portafolio completo.
  * Transición fluida al hacer clic en **"Ingresar para ver la página completa"**.
  * Posibilidad de reabrir el resumen ejecutivo en cualquier momento desde el botón **"Resumen"** de la barra de navegación.

* **Accesibilidad Web Integral (WCAG 2.1 Nivel AA / AAA):**
  * Enlace accesible de salto al contenido principal (`.skip-link`).
  * Canal dinámico para lectores de pantalla mediante `aria-live="polite"` (`#a11y-announcer`).
  * Navegación completa por teclado con indicadores de foco visibles de alto contraste.
  * Control interactivo flotante para ajustar el tamaño de fuente (`A-`, `A`, `A+`) en tiempo real.

* **Modo Oscuro / Claro Automático y Manual:**
  * Selector de tema disponible tanto en la pantalla de bienvenida como en la barra flotante.
  * Detección automática de la preferencia del sistema (`prefers-color-scheme`).
  * Persistencia de la selección del usuario en `localStorage`.

* **Estructura y Contenido Profesional (7 Secciones):**
  1. **Acerca de mí:** Perfil, roles y datos esenciales de contacto y ubicación.
  2. **Estudios:** Carrera universitaria en Ingeniería en Software y certificaciones analíticas y de soporte vital.
  3. **Experiencia Laboral:** Trayectoria operativa y comercial (Pical S.A., TÍA S.A., Carl's Jr.).
  4. **Habilidades y Lenguajes:** Barras de nivel semánticas (C#, Python, Java, POS, inventarios, habilidades blandas e idiomas).
  5. **Proyectos:** Proyecto destacado **Luuv** (App web interactiva con Java, Spring Boot, WebSockets y despliegue en la nube).
  6. **Contactos:** Vías de comunicación directa y formulario accesible validado en cliente.
  7. **Redes Profesionales:** Enlaces seguros y directos a GitHub y LinkedIn (`@epdodev`).

## 🛠️ Tecnologías Empleadas

* **HTML5:** Marcado semántico, metadatos SEO y atributos ARIA explícitos.
* **CSS3:** Custom Properties (variables CSS), Flexbox, CSS Grid, Glassmorphism, animaciones y transiciones fluidas sin dependencias de frameworks externos.
* **JavaScript (Vanilla ES6+):** Lógica modular, persistencia en `localStorage`, control de foco, observador de secciones (`IntersectionObserver`) y validación accesible.

## 🚀 Despliegue y Visualización Local

Para visualizar el proyecto en local:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/epdodev/PagePortafolioWeb-AgentA.git
   ```
2. Abre la carpeta del proyecto en tu editor o navegador web:
   * Puedes abrir directamente el archivo `index.html` en cualquier navegador moderno.
   * O servirlo con cualquier servidor estático (como Live Server en VS Code o `npx serve .`).
